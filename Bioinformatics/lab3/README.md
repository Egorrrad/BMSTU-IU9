# Лабораторная работа 3. Алгоритм Хиршберга для глобального выравнивания

Цель лабораторной — изучить алгоритм Хиршберга, который решает задачу глобального парного выравнивания последовательностей с использованием линейной памяти \(O(min(m,n)\) вместо квадратичной \(O(mn)\).

## Проблема памяти в алгоритме Нидлмана-Вунша

Классический алгоритм NW требует хранения полной матрицы размером \((n+1) × (m+1)\), что приводит к сложности по памяти \(O(nm)\). Для длинных последовательностей это становится непрактичным.

Алгоритм Хиршберга решает эту проблему, используя подход "разделяй и властвуй" в комбинации с наблюдением, что для вычисления последней строки матрицы NW достаточно хранить только предыдущую строку.

## Принцип работы алгоритма

Алгоритм Хиршберга работает рекурсивно:

1. **Базовый случай:** если одна из последовательностей пуста или имеет длину 1, используем обычный NW.

2. **Разделение:** делим меньшую из двух последовательностей пополам в позиции `mid_i`.

3. **Поиск точки разделения:** вычисляем последние строки динамического программирования для левой половины (прямое направление) и правой половины (обратное направление). Функция `get_mid_j` находит позицию `mid_j` во второй последовательности, максимизируя сумму скоров из этих двух строк. Эта сумма соответствует скору оптимального пути, проходящего через точку `(mid_i, mid_j)`.

4. **Рекурсивный вызов:** решаем две подзадачи для левой и правой частей.

5. **Объединение:** конкатенируем результаты обеих подзадач.
